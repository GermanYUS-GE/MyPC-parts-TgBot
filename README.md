# Telegram-бот для учёта комплектующих и сборок ПК

Бот помогает вести склад компьютерных комплектующих и собирать из них компьютеры прямо в Telegram.

## Что умеет

**Склад комплектующих.** Хранит материнские платы, процессоры, оперативную память, SSD, HDD и видеокарты. Для каждой детали записываются характеристики: сокет, тип памяти, частота, объём, число ядер и потоков, состояние накопителя, особенности работы и цена. Деталь можно добавить, изменить или удалить. Значения выбираются кнопками, а числа бот проверяет: например, у шестиядерного процессора не получится указать 26 потоков.

**Сборки.** Сборка создаётся из деталей, которые уже есть на складе. Ей можно дать своё название, например «Офисный ПК». Бот показывает состав сборки и её итоговую себестоимость, а при несовместимости (разные сокеты, неподходящий тип памяти) выводит предупреждение. Деталь в сборке пропадает из свободного склада, а при удалении из сборки возвращается на место.

**Хранение и доступ.** Данные сохраняются в файле на компьютере и не пропадают при выключении бота. Пользоваться ботом может только его владелец.

## Запуск

1. Установить Python 3.10 или новее.
2. Установить библиотеку: `pip install -r requirements.txt`
3. Создать бота у [@BotFather](https://t.me/BotFather) и получить токен.
4. Узнать свой числовой Telegram id у [@userinfobot](https://t.me/userinfobot).
5. Задать настройки и запустить (Windows, каждую команду отдельно):

```
set BOT_TOKEN=токен_от_BotFather
set OWNER_ID=твой_telegram_id
python main.py
```

На Mac и Linux вместо `set` используется `export`.

Токен нельзя хранить в коде или выкладывать публично: он даёт полный доступ к боту.
Файл базы `warehouse.db` создаётся рядом с `main.py` автоматически и в репозиторий не попадает.

## Статус

Учебный проект. Первая версия бота для склада: комплектующие и сборки. Планы: продажи сборок и учёт прибыли.
