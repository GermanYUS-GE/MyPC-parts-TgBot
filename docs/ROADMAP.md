# Дорожная карта бота: от 0.6 до 1.0

Составлена 2026-11-23. Оригинал — документ «Дорожная карта бота от 0.6 до 1.0» в проекте claude.ai.

## Цель и критерии версии 1.0

Бот 1.0 — это рабочий инструмент: он ведёт склад, сборки и продажи, показывает прибыль и капитал и не теряет данные. Его можно использовать каждый день и показать на GitHub как готовый проект.

Бот считается готовым, когда выполнено всё из списка:
- Весь цикл «купил деталь → положил на склад → собрал → продал» проходит без ручных обходных путей.
- Для каждой продажи видны закупка, цена продажи, прибыль, наценка и маржа в процентах.
- Бот предупреждает, если цена ниже себестоимости.
- Есть экран капитала (деньги + склад) с динамикой по месяцам.
- Видно, сколько дней лежит каждая деталь, и какие позиции залежались.
- Данные защищены: автоматические бэкапы базы, бот работает 24/7 на сервере.
- На GitHub есть README со скриншотами, CHANGELOG и демо-данные.

## Версии по шагам

Порядок: 0.7 → 0.8 → 0.9 → 0.95 → 1.0. Версия выходит только после проверки пользователем; в конце каждой — признак готовности. Перед каждым шагом можно добавить или убрать пункты.

### 0.7 — Порядок на складе
- Убрать статусы «готова/черновик» и любую проверку комплектности: «Продать сборку» доступна, если в сборке есть хотя бы одна деталь.
- Новые категории: «Блок питания» (мощность; линия 12V в ваттах или амперах, можно пропустить) и «Кулер для процессора» (тип башенный/боксовый, медные трубки, подсветка и её тип; всё, кроме типа, можно пропустить). Из «Прочих расходов» оба убираются.
- Сборка «как Лего»: начать можно с любой детали. Совместимость: плата ↔ память (тип DDR), плата ↔ процессор (сокет), плата ↔ число планок (слоты). Несовместимые детали в списке выбора не показываются. Остальное (корпус, видеокарта, SATA-накопители, блок питания, кулер) подходит к чему угодно.
- У материнской платы новое необязательное поле «Слотов M.2». Если оно указано, NVMe-накопителей в сборке не больше, чем слотов M.2.
- Меню из трёх пунктов; «История и статистика» объединены.
- Количество у всех категорий; продажа части позиции: цена — общая за проданные штуки, себестоимость — пропорциональная доля, остаток сохраняет прежнюю цену за штуку.
- Кнопка «✂️ Отделить N шт.».
- Дата поступления `added_at` у каждой детали: новая ставится автоматически, у любой детали её можно поменять (для реальных деталей, купленных раньше).
- Предупреждение, если цена продажи ниже себестоимости.

**Готово, когда:** сборка продаётся без видеокарты и корпуса, часть позиции продаётся и остаток считается верно, сборка начинается с памяти и предлагает только подходящие платы.

### 0.8 — Партии и покупка целым компьютером
- Особенности по штукам: базовое значение + исключения (например, у 4 из 5 SSD здоровье 100%, у одного 87%).
- Исключения автоматически выделяются в отдельные записи.
- **Покупка целым компьютером (лотом).** Пример: куплен ПК с периферией за 400 лари; нужно понять, сколько из этих 400 приходится на видеокарту, процессор, плату, память, блок питания, накопитель, корпус, Wi-Fi и Bluetooth адаптеры.
  - «Добавить покупку целиком»: общая цена + список того, что вошло. Детали сразу попадают на склад со своей долей цены и общей датой поступления.
  - Общая цена делится по «весу» деталей. Сумма долей всегда равна цене покупки (остаток от округления уходит в самую дорогую деталь).
  - **Способ 1 — оценка пользователя.** Для каждой детали пользователь пишет, во сколько, по его мнению, ему обошлась эта деталь. В боте это будет подписано прямо: **«себестоимость, а не рыночная цена»**, чтобы не путать. По этим оценкам цена покупки делится пропорционально: если оценки 150 + 60 + 40 + … = 500, а заплачено 400, каждая доля умножается на 400 / 500.
  - **Способ 2 — автоматические веса** (без интернета и ИИ, по характеристикам):
    - видеокарта: маркеры RTX / GTX / RX в названии, тип памяти (GDDR6 > GDDR5 > DDR3), объём VRAM;
    - процессор: свежесть сокета, ядра, потоки, частота — баллы складываются в вес;
    - материнская плата: сокет, тип памяти (DDR5 > DDR4 > DDR3), слоты M.2;
    - память: тип и общий объём; накопители: тип (NVMe > SATA SSD > HDD) и объём;
    - блок питания: мощность; кулер: тип и трубки; корпус, адаптеры, периферия — небольшой фиксированный вес.
  - Можно смешивать: для части деталей пользователь вписывает оценку, остальные считаются по весам. Перед сохранением все доли видны и любую можно поправить.
  - Понадобится категория «Прочее» для мелочей (Wi-Fi/Bluetooth адаптер, периферия).
  - Основа уже есть: `split_part` делит цену пропорционально.

**Готово, когда:** позицию из пяти штук с разными параметрами можно завести, разделить и продать по частям; покупку целого ПК можно завести одной операцией, и цена разложена по деталям.

### 0.9 — Деньги и скорость
- Экран капитала: деньги (вручную) + склад по закупке + сборки по себестоимости.
- Снимок капитала раз в месяц и рост в процентах.
- Учёт вложений и выводов денег, чтобы они не искажали рост.
- Наценка и маржа в процентах по каждой продаже и за период.
- Дни на складе, прибыль в день, доходность в месяц; список залежавшегося.
- Подсказка цены: минимум без убытка и цена под целевую наценку.

**Готово, когда:** по любой проданной сборке видно прибыль, наценку, маржу и срок продажи, а на экране капитала — рост за месяц.

### 0.95 — Удобство
- Поиск по складу.
- Фильтр совместимости в списках выбора: основное (сокет, тип памяти, слоты, M.2) сделано в 0.7; здесь — доработки, если понадобятся.
- Шаблон и копирование сборки для типовых заказов.

**Готово, когда:** типовую сборку можно собрать за пару минут.

## Как бот отвечает на вопросы бизнеса

| Вопрос | Как бот отвечает | Версия |
| --- | --- | --- |
| Сколько я заплатил? | Закупка хранится у каждой детали; себестоимость сборки = детали + расходы + авто-расход | уже есть |
| Не продаю ли я в минус? | Предупреждение при цене ниже себестоимости, с суммой убытка | 0.7 |
| Как быстро продаётся? | Дата поступления и продажи, дни на складе, список залежавшегося | 0.7 (данные) / 0.9 (экран) |
| Что выгоднее: дороже и долго или дешевле и быстро? | Прибыль в день и доходность в месяц по каждой продаже | 0.9 |
| Сколько у меня капитала и как он растёт? | Деньги + склад + сборки; снимок раз в месяц, рост в % | 0.9 |

## Определения

Наценка считается от закупки, маржа — от цены продажи. Пример: купил за 50, продал за 75, прибыль 25.

| Показатель | Формула | Пример |
| --- | --- | --- |
| Наценка | прибыль / закупка | 25 / 50 = 50% |
| Маржа | прибыль / цена продажи | 25 / 75 ≈ 33% |
| Рост капитала | (конец − начало) / начало | (1250 − 1000) / 1000 = +25% |
| Прибыль в день | прибыль / дни на складе | 25 / 10 дней = 2,5 в день |
| Доходность в месяц | прибыль / закупка за 30 дней | 50% за 10 дней ≈ 150% в месяц при повторении |

Пример скорости: деталь за 100, продана за 130 через 30 дней — наценка 30%, 1 в день. Продана за 120 через 5 дней — наценка 20%, 4 в день. Быстрая продажа даёт больше, если освободившиеся деньги вкладываются снова.

Вложения и выводы денег искажают рост капитала, поэтому их нужно учитывать отдельно.
