# Запуск бота на Railway (24/7)

Бот на Railway работает круглосуточно, даже когда компьютер выключен. База хранится на постоянном диске (Volume).

## Что уже готово в коде
- `railway.json`: команда запуска `python main.py`, перезапуск при сбое.
- `requirements.txt`: aiogram 3.32+. `.python-version`: Python 3.13.
- Переменная `DATA_DIR`: папка для базы. На Railway это `/data` (туда подключается Volume).
- «💾 Резервная копия» в главном меню: файл базы присылается в Telegram, а восстанавливается отправкой файла с подписью `/restore`. Каждый день в 23:00 бот сам присылает копию владельцу.
- `.env` и `*.db` на сервер не отправляются (они в `.gitignore`). Токен задаётся в настройках Railway.

## Шаги

**1. Аккаунт (делает пользователь).** Зарегистрироваться на railway.com и выбрать план Hobby ($5 в месяц, эти $5 идут в счёт использования; маленькому боту с базой обычно хватает). Перед оплатой проверить актуальные цены на railway.com/pricing.

**2. Railway CLI.** Это программа, которая отправляет папку с ботом на сервер (без GitHub). Скачивается с официальной страницы github.com/railwayapp/cli, раздел Releases (файл для Windows `x86_64-pc-windows-msvc`).

**3. Вход.** `railway login`: откроется браузер, пользователь подтверждает вход.

**4. Проект и отправка кода.** Из папки `C:\Python\Bot_PC`:
```
railway init
railway up
```

**5. Настройки в панели Railway (делает пользователь):** в сервисе бота:
- *Variables:* `BOT_TOKEN` (токен), `OWNER_ID` (ваш id), `DATA_DIR` = `/data`.
- *Volume:* добавить (Add Volume), путь подключения (Mount path) `/data`.

После этого Railway перезапустит бота.

**6. Остановить бота на компьютере.** Две копии одного бота мешают друг другу (Telegram отдаёт сообщения то одной, то другой).

**7. Перенос базы.**
1. До остановки локального бота: «💾 Резервная копия» → «📤 Прислать копию сейчас». Бот пришлёт файл `.db`.
2. Когда бот на Railway запустится: переслать ему этот файл и в подписи написать `/restore`.
3. Бот ответит «✅ База восстановлена: деталей в ней N».

## Обновление бота потом
После правок кода — снова `railway up` из папки проекта. База на Volume не пропадает.

## Если что-то не так
- Логи: в панели Railway, вкладка Deployments → View logs. Строка `База: /data/warehouse.db` значит, что база на постоянном диске.
- Если в логах `База: /app/warehouse.db`, значит, не задан `DATA_DIR=/data`: база пропадёт при следующем обновлении.
